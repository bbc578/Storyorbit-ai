# StoryOrbit AI PRD

## Product Goal

StoryOrbit AI helps creators test and develop story universes instead of only generating isolated text.

The product is built for:

- short-drama writers who need hooks, reversals, and episode outlines
- web-novel authors who need stable long-running character arcs
- game narrative designers who need quest branches and NPC consistency
- IP creators who need reusable world rules and character memory

## Core User Problem

Creators can ask AI to write scenes, but they still need to know whether the story logic works:

- Do character motives stay consistent?
- Does the next plot event create enough tension?
- Are there better branches for the target audience?
- Can the same world become a short drama, serial outline, or game quest chain?

StoryOrbit AI focuses on these structural problems.

## MVP Scope

The current MVP includes:

1. Beginner mode for turning one idea into a full story universe.
2. Story Bible editor for genre, audience, rules, theme, and core conflict.
3. Character memory engine with goals, hidden motives, fears, speech style, relationships, and hard rules.
4. Plot event simulation with selected participating characters.
5. Multi-agent cloud workflow with character, director, critic, and scriptwriter agents.
6. Offline rule engine for use without an API key.
7. Plot stress test across 10 story-quality dimensions.
8. Relationship graph and branch map.
9. Export outputs for Story Bible, character memory pack, short-drama storyboard, serial outline, game quest chain, and project pitch.

## User Flow

1. A creator enters a story idea or starts from the professional workspace.
2. The system creates or updates the Story Bible.
3. The creator edits character memory cards.
4. The creator enters the next plot event.
5. Character agents respond according to their memory and rules.
6. The director agent proposes plot branches.
7. The critic agent pressure-tests the result.
8. The scriptwriter agent formats the output into practical deliverables.
9. The creator exports the result as Markdown.

## Deliverables

The project can produce:

- Story Bible
- character memory pack
- short-drama storyboard
- serial web-novel outline
- game quest chain
- project pitch

## Non-Goals

- It is not a generic chatbot.
- It does not replace the creator's final judgment.
- It should not be used to copy existing copyrighted IP.
- It does not expose provider API keys to end users.

## Success Criteria

- A new user can generate a usable story universe in under 15 minutes.
- A creator can run multiple plot simulations without rebuilding the whole project.
- The stress test gives clear revision direction.
- Exported materials are ready to paste into a pitch, outline, or production document.
